## About

**RemoveBedRangeLimit** removes the vanilla restriction on bed interaction distance, which can cause the **"Bed is too far away"** message.

With this mod, you can interact with a bed from any distance without the usual range limitation.

### Features

* Removes the bed interaction distance limit
* Enables bed interaction from any range

## Installation

1. Download the latest release from the [Releases](https://github.com/RealBatu20/RemoveBedRangeLimit-MCPE_MOD/releases) page.
2. Install the mod with a supported Minecraft Bedrock mod launcher such as [Levilaunchroid](https://github.com/LiteLDev/LeviLaunchroid)
3. Enable the mod.
4. Launch Minecraft and use the mod.

> [!NOTE] 
> This is a native Minecraft Bedrock mod. Compatibility depends on the Minecraft version and mod-loading environment supported by each release.
